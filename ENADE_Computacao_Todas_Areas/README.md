# ENADE — Todas as áreas relacionadas à Computação (INEP)

Atualizado em 05/11/2026. Fonte oficial: https://www.gov.br/inep/pt-br/areas-de-atuacao/avaliacao-e-exames-educacionais/enade/provas-e-gabaritos

Pasta antiga `ENADE_Engenharia_de_Computacao/` mantida como subset (Engenharia + legado). Esta pasta `ENADE_Computacao_Todas_Areas/` é a completa.

## Resumo

**105 PDFs, ~159 MB**, todos `PDF document` válidos (verificado com `file`).

- **Núcleo computação (84 PDFs):** Engenharia de Computação + Ciência da Computação + Sistemas de Informação + CST Análise e Desenvolvimento de Sistemas + CST Redes de Computadores + CST Gestão da Tecnologia da Informação + legado "Computação" 2005/2008/2011.
- **Relacionadas Automação (21 PDFs):** Engenharia de Controle e Automação (2014/2017/2019/2023) + Tecnologia em Automação Industrial (2008/2011/2014). Incluídas por terem forte relação com computação/embarcados, mas são área distinta no INEP. Se quiser só computação estrita, ignore a pasta `relacionadas_Automacao/`.

> **Engenharia de Software:** não existe como área separada no ENADE. O que existe é **Engenharia de Computação / Engenharia da Computação** — o conteúdo de software está dentro dela. Não há arquivo `software` em nenhum ano (verificado por busca em todas as abas 2004–2025).
